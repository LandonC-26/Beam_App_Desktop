# Beam Designer

Beam Designer is a Python/Tkinter desktop app for analyzing simply supported
beams and cantilevers. It plots shear, moment, and deflection, checks bending
stress and deflection limits, and can save designs or export CSV/PDF reports.

## Install

Requires Python with Tkinter. Install the plotting dependency:

```powershell
python -m pip install -r requirements.txt
```

## Run

```powershell
python app.py
```
